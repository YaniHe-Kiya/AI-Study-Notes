YOLOv8 Object Detection¶

In this experiment, I practiced how to train an object detection model using YOLOv8 and how to make predictions with the trained model. I previously learned object detection from Xiaotudui and used the same dataset to continue this experiment.

1. Read YOLO Labels and Visualize Bounding Boxes¶

First, I practiced how to read YOLO label files, convert normalized YOLO coordinates into pixel coordinates, and draw bounding boxes on an image.

In [82]:
import cv2
import matplotlib.pyplot as plt

image_path = "my_dataset/Train/images/new1.jpg"
label_path = "my_dataset/Train/labels/new1.txt"

image = cv2.imread(image_path)
image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
print(image.shape)
print(image.shape)

h,w = image.shape[:2]
print(h,w)

with open(label_path,"r") as f:
    labels = f.readlines()  #read labels line by line

print(labels)

class_names = [
    "motor",
    "no helmet",
    "number",
    "with helmet"
]

#split labels
for label in labels:
    values = label.strip().split()   
    class_id = int(values[0])
    # YOLO format labels, x_center  y_center  width  height, normalized coordinates
    x_center = float(values[1])
    y_center = float(values[2])
    box_width = float(values[3])
    box_height = float(values[4])
    print(
        class_id,
        x_center,
        y_center,
        box_width,
        box_height
    )
    # Change normalized coordinates (x_center,y_center,width,height) into (x1,y1,x2,y2) 
    # where (x1,y1) is the location of the left up corner point, (x2,y2) is the right bottom corner point
    x_center = x_center * w
    y_center = y_center * h 
    box_width = box_width * w
    box_height = box_height * h

    x1 = int(x_center - box_width/2)
    y1 = int(y_center - box_height/2)
    x2 = int(x_center + box_width/2)
    y2 = int(y_center + box_height/2)

    print(x1,y1,x2,y2)

    cv2.rectangle(image,(x1,y1),(x2,y2),(255,0,0),2)
    cv2.putText(image,class_names[class_id],(x1,y1-4),cv2.FONT_HERSHEY_SIMPLEX,0.6,(255,0,0),2)


plt.imshow(image)
plt.axis("off")
plt.show()

2. Load and Check the Dataset¶

Next, I practiced how to load the image and label files and organize them as image-label pairs. When using the Ultralytics YOLO training pipeline, Steps 1 and 2 are not strictly necessary because Ultralytics automatically loads and processes the dataset. However, manually completing these steps helped me understand how YOLO data is organized and read.

import os

image_dir = "my_dataset/Train/images"
label_dir = "my_dataset/Train/labels"

image_files = os.listdir(image_dir)
print("Total files:", len(image_files))

dataset = []

for image_name in image_files:
    img_path = os.path.join(image_dir,image_name)
    file_name = os.path.splitext(image_name)[0]
    label_name = file_name + ".txt"
    label_path = os.path.join(label_dir,label_name)
    with open(label_path,"r") as f:
            labels = f.readlines()
    dataset.append({
          "image_path":img_path,
          "label_path":label_path,
          "labels":labels  
    }
    )

image = cv2.imread(dataset[0]["image_path"])
