DINOv2 Feature Similarity and Image Retrieval¶

This experiment investigates how pretrained DINOv2 features can be used to measure image similarity and retrieve visually similar images from the CIFAR-10 dataset.

1. Feature Extraction¶

The pretrained DINOv2 ViT-S/14 model was used as a visual feature extractor. A subset of 1,000 images was selected from the CIFAR-10 test dataset.

Each image was resized to 224 × 224 pixels and normalized before being passed through DINOv2. The model converts each image into a 384-dimensional global feature vector.

After processing all 1,000 images, the extracted features and labels were combined into two tensors:

Feature tensor: [1000, 384] Label tensor: [1000]

This means that each image is represented by a 384-dimensional vector in the DINOv2 feature space.

from torch.utils.data import DataLoader,Subset

#Load data
test_dataset = torchvision.datasets.CIFAR10(root = "../data", train=False, transform = transform,download=True)
subset = Subset(test_dataset, range(1000))
test_dataloader = DataLoader(subset,batch_size=64,shuffle=False)


all_features = []
all_labels = []
step = 1

with torch.no_grad():
    for images, labels in test_dataloader:
        images = images.to(device)
        features = dinov2(images)
        all_features.append(features.cpu())
        all_labels.append(labels)
        print("Step: ",step)
        step += 1

all_features = torch.cat(all_features,dim=0)
all_labels = torch.cat(all_labels,dim=0)

print("Feature shape:", all_features.shape)
print("Label shape:", all_labels.shape)

2. Calculate Cosine Similarity¶

One image was selected as the query image. Its 384-dimensional DINOv2 feature vector was compared with the feature vectors of all 1,000 images. Cosine similarity was used to measure the similarity between two feature vectors.

3. Top-K Similar Image Retrieval¶

The cosine similarity scores were ranked using torch.topk().

Because the query image itself normally has the highest similarity score, the first result was removed. The next six images were then selected as the Top-6 most similar images.

The query image and retrieved images were visualized together with:

CIFAR-10 class labels Cosine similarity scores

This makes it possible to directly compare semantic class information with the similarity learned by DINOv2.

import torch.nn.functional as F

similarities = F.cosine_similarity(
    query_feature.unsqueeze(0),
    all_features,
    dim=1
)

top_k = 6
values, indices = torch.topk(
    similarities,
    k=top_k + 1
)

print("Top similarity scores:", values)
print("Top image indices:", indices)

# Remove query image itself
values = values[1:]
indices = indices[1:]

fig, axes = plt.subplots(1, top_k + 1, figsize=(18, 3))

# Query image
query_image, query_label = subset[query_index]

display_image = query_image * std + mean
display_image = display_image.clamp(0, 1)

axes[0].imshow(display_image.permute(1, 2, 0))
axes[0].set_title(
    f"Query\n{test_dataset.classes[query_label]}"
)
axes[0].axis("off")


# Top-K similar images
for i, idx in enumerate(indices):

    image, label = subset[idx.item()]

    display_image = image * std + mean
    display_image = display_image.clamp(0, 1)

    axes[i + 1].imshow(
        display_image.permute(1, 2, 0)
    )

    axes[i + 1].set_title(
        f"{test_dataset.classes[label]}\n"
        f"Sim: {values[i]:.3f}"
    )

    axes[i + 1].axis("off")

plt.tight_layout()
plt.show()
