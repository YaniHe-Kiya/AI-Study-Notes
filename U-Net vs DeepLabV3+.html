U-Net vs DeepLabV3+ on PASCAL VOC 2012¶

In this experiment, I compared two popular image segmentation models, U-Net and DeepLabV3+, on the PASCAL VOC 2012 dataset.

The dataset was downloaded using kagglehub.

4. Define Dataset¶

A custom PyTorch Dataset is used to load the image-mask pairs. Bilinear interpolation is used for RGB images, while nearest-neighbor interpolation is used for segmentation masks to preserve the original class IDs.

In [3]:
from PIL import Image
import numpy as np
import torch

from torch.utils.data import Dataset
from torchvision.transforms import functional as F
from torchvision.transforms import InterpolationMode


class VOCDataset(Dataset):

    def __init__(self, pairs, image_size=256):
        self.pairs = pairs
        self.image_size = image_size

    def __len__(self):
        return len(self.pairs)

    def __getitem__(self, idx):

        image_path, mask_path = self.pairs[idx]

        image = Image.open(image_path).convert("RGB")
        mask = Image.open(mask_path)

        # Resize image
        image = F.resize(
            image,
            size=(self.image_size, self.image_size),
            interpolation=InterpolationMode.BILINEAR
        )

        # Resize mask
        mask = F.resize(
            mask,
            size=(self.image_size, self.image_size),
            interpolation=InterpolationMode.NEAREST
        )

        # Image -> Float Tensor
        image = F.to_tensor(image)

        # ImageNet normalization
        image = F.normalize(
            image,
            mean=[0.485, 0.456, 0.406],
            std=[0.229, 0.224, 0.225]
        )

        # Mask -> Long Tensor
        mask = np.array(mask)
        mask = torch.from_numpy(mask).long()

        return image, mask

6. Configure U-Net and DeepLabV3+¶

In this experiment, U-Net and DeepLabV3+ are implemented using the segmentation_models_pytorch library.

To make the comparison as fair as possible, both models use the same ResNet34 encoder pretrained on ImageNet. The main difference between the two models is therefore the segmentation architecture and decoder design.

In [5]:

7. Shared Training Configuration and train function definition¶

In [6]:
from torch import nn

loss_fn = nn.CrossEntropyLoss(ignore_index=255)
LEARNING_RATE = 1e-3
EPOCH =50

unet_optimizer = torch.optim.Adam(unet.parameters(),
                                  lr = LEARNING_RATE)
deep_optimizer = torch.optim.Adam(deeplabv3plus.parameters(),
                                  lr=LEARNING_RATE)


def train_model(model, optimizer):
    history = {
        "train_loss":[],
        "val_loss":[],
        "miou":[],
        "dice":[] }
    
    for i in range(EPOCH):
        total_loss_train = 0
        model.train()
        for images, masks in train_dataloader:
            images = images.to(device)
            masks = masks.to(device)
            optimizer.zero_grad()
            output = model(images)
            loss_train = loss_fn(output,masks)
            loss_train.backward()
            optimizer.step()
            total_loss_train += loss_train.item()

        avg_train_loss = total_loss_train / len(train_dataloader)
        print("Epoch{}|Average Loss Train:{:.4f}".format(i+1,avg_train_loss))

        model.eval()
        total_loss_val = 0
        num_classes = 21
        total_intersection = torch.zeros(num_classes, device = device)
        total_union = torch.zeros(num_classes, device = device)
        total_area= torch.zeros(num_classes, device = device)

        with torch.no_grad():
            for images, masks in val_dataloader:
                images = images.to(device)
                masks = masks.to(device)
                output = model(images)
                loss_val = loss_fn(output,masks)
                total_loss_val += loss_val.item()

                #IoU & dice
                pred = output.argmax(dim=1)
                valid = masks != 255
                pred = pred[valid]
                target = masks[valid]

                for class_id in range(num_classes):
                    pred_class = pred == class_id
                    target_class = target == class_id
                
                    intersection = (pred_class & target_class).sum()
                    union = (pred_class | target_class).sum()
                    area = pred_class.sum() + target_class.sum()
                
                    total_intersection[class_id] += intersection
                    total_union[class_id] += union
                    total_area[class_id] += area

        avg_val_loss = total_loss_val/len(val_dataloader)
        print("Average Loss Val:{}".format(avg_val_loss))
        ious = []
        dices = []
        for class_id in range(num_classes):
            if total_union[class_id] >0:
                iou = (total_intersection[class_id]/total_union[class_id])
                ious.append(iou)
            if total_area[class_id] >0:
                dice = 2*total_intersection[class_id]/total_area[class_id]
                dices.append(dice)

        miou = torch.stack(ious).mean().item()
        print("mIoU:{}".format(miou))
        mdice = torch.stack(dices).mean().item()
        print("dice:{}".format(mdice))

        history["train_loss"].append(avg_train_loss)
        history["val_loss"].append(avg_val_loss)
        history["miou"].append(miou)
        history["dice"].append(mdice)

    return history

Discussion¶

Both U-Net and DeepLabV3+ improved during training, but DeepLabV3+ achieved better segmentation performance overall.

After 50 epochs, U-Net reached an mIoU of about 0.25 and a Dice score of 0.37, while DeepLabV3+ achieved a higher mIoU of about 0.33 and a Dice score of 0.45.

The training loss of both models continued to decrease, while the validation loss became unstable and increased in later epochs. This suggests that both models started to overfit the training data.

Overall, DeepLabV3+ performed better than U-Net on this experiment, although further improvements could be made using data augmentation, learning-rate tuning, or early stopping.
