DINOv2 Feature Visualization¶

This experiment visualizes the feature representations extracted by a pretrained DINOv2 model. The objective is to investigate whether images from different CIFAR-10 classes naturally form semantic clusters in the DINOv2 feature space without additional training.

1. Extract DINOv2 Features¶

In [1]:
import torch
import torchvision
import torchvision.transforms as transforms
from torch.utils.data import DataLoader,Subset


device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

dinov2 = torch.hub.load(
    "facebookresearch/dinov2",
    "dinov2_vits14"
)
dinov2 = dinov2.to(device)
dinov2.eval()
transform = transforms.Compose([
    transforms.Resize((224,224)),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=(0.485, 0.456, 0.406),
        std=(0.229, 0.224, 0.225)
    )])


#Load data
test_dataset = torchvision.datasets.CIFAR10(root = "../data", train=False, transform = transform,download=True)
subset = Subset(test_dataset, range(1000))
test_dataloader = DataLoader(subset,batch_size=64,shuffle=False)


all_features = []
all_labels = []
step = 1

with torch.no_grad():
    for images, labels in test_dataloader:
        images = images.to(device)
        features = dinov2(images)
        all_features.append(features.cpu())
        all_labels.append(labels)
        print("Step: ",step)
        step += 1

all_features = torch.cat(all_features,dim=0)
all_labels = torch.cat(all_labels,dim=0)

print("Feature shape:", all_features.shape)
print("Label shape:", all_labels.shape)

3. PCA Observation¶

In [3]:
import matplotlib.pyplot as plt

class_names = test_dataset.classes

plt.figure(figsize=(10, 8))

for class_id, class_name in enumerate(class_names):
    mask = all_labels.numpy() == class_id

    plt.scatter(
        features_pca[mask, 0],
        features_pca[mask, 1],
        label=class_name,
        alpha=0.6
    )

plt.xlabel("PC1")
plt.ylabel("PC2")
plt.title("DINOv2 Feature Visualization with PCA")
plt.legend()
plt.show()

Even with simple linear PCA, DINOv2 features exhibit clear semantic structure. Animal and vehicle classes are largely separated, while semantically similar categories, such as automobile and truck, tend to occupy nearby regions in the feature space.

5. PCA vs t-SNE¶

PCA and t-SNE provide complementary views of the DINOv2 feature space.

PCA preserves the major directions of variation in the complete feature space and therefore provides a useful view of its global structure. In this experiment, PCA already reveals a broad separation between animal and vehicle classes.

t-SNE focuses more strongly on local neighbourhood relationships and can reveal smaller clusters that may not be clearly visible in the PCA representation.

6. Conclusion¶

This experiment demonstrates that pretrained DINOv2 features contain meaningful semantic information even without fine-tuning on CIFAR-10.

The PCA visualization already reveals broad semantic organization, particularly the separation between animal and vehicle categories. The feature visualization therefore provides qualitative evidence that DINOv2 learns transferable visual representations in which semantically related images tend to occupy similar regions of the feature space.

PCA and t-SNE provide complementary ways to inspect these representations: PCA highlights global structure, while t-SNE provides a more detailed view of local clustering.
